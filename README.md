# Silverreed-PointCam

シルバリード電子編み機の必須部品であるポイントカムを3Dプリンタで作成する

Silver Reed 用 PointCam 部品の再現・3Dプリントを目的とした Blender 生成モデルです。

このリポジトリでは、三面図と実物写真から形状を読み取り、実測値を反映しながらモデルを更新してきた履歴を整理しています。

## 現行モデル

最新版の Blender 生成スクリプト:

- `src/silverreed_pointcam_blender.py`

Blender の **Scripting** ワークスペースでスクリプトを開き、`Run Script` を実行するとモデルを生成します。

## 最終仕様

主要寸法は以下です。

| 項目 | 寸法 |
|---|---:|
| 本体 | 30.0 × 11.6 × 6.7 mm |
| 外周面取り | 0.30 mm |
| U字ノッチ | 幅1.6 × 奥行5.0 × 高さ6.2 mm |
| U字ノッチ中心間隔 | 6.5 / 6.5 / 6.5 mm |
| 四角くぼみ | 5.2 × 5.2 mm、深さ5.0 mm |
| ダボ | φ1.5 × 高さ1.5 mm |
| ダボ中心間隔 | 6.5 / 13.0 / 6.5 mm |
| 上面文字 | `6.5`、約18 pt相当、凸0.25 mm |
| センターマーク | 幅0.8 × 長さ1.6 × 凸0.25 mm |

詳細は [`docs/FINAL_SPEC.md`](docs/FINAL_SPEC.md) を参照してください。

## 座標系

- X: 本体幅 30 mm 方向
- Y: 本体奥行 11.6 mm 方向
- Z: 高さ方向
- 本体中心: `X=0, Y=0`
- 本体下面: `Z=0`
- 本体上面: `Z=6.7`
- U字ノッチ開口側: `-Y`

## 設計履歴

寸法決定・変更の経緯は [`CHANGELOG.md`](CHANGELOG.md) にまとめています。

## Blenderでの実行

1. Blenderを開く
2. `Scripting` ワークスペースを選択
3. `Open` から `src/silverreed_pointcam_blender.py` を開く
4. `Run Script` を実行
5. 生成された `Silverreed_PointCam` を確認
6. 3Dプリント用に必要なら STL / 3MF へエクスポート

## 注意

U字ノッチのX位置、ダボのX位置は最終的なピッチ条件に基づいて確定しています。

四角くぼみのXY位置とダボのY位置は、元図面の寸法比から求めた値です。実機への嵌合精度をさらに上げる場合は、現物のノギス実測値で再調整してください。
